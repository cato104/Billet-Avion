✈️ Billet Avion

L'IA cherche pour vous des billets d'avion moins chers

Clé API (optionnelle — mode « recherche directe »)

Vous n'en avez pas besoin si vous utilisez le bouton « ✨ Lancer dans Claude », qui passe par votre abonnement Claude Pro/Max. La clé API ne sert qu'au mode avancé où les résultats s'affichent directement dans cette page. Attention : l'API est facturée séparément de l'abonnement Pro (paiement à l'usage). Pour en créer une :

  1. Créez un compte sur console.anthropic.com
  2. Dans « API Keys », créez une clé (elle commence par sk-ant-)
  3. Collez-la ci-dessous

🔒 Votre clé est enregistrée uniquement dans votre navigateur (elle n'est envoyée qu'à l'API d'Anthropic). Chaque recherche coûte quelques centimes, débités sur votre compte Anthropic.

Comment ça marche ?

  • 🔥 Offres en direct — les vrais prix, tout de suite : un moteur de recherche de vols intégré dans la page + des raccourcis vers Google Flights.
  • 🤖 Analyses IA (onglets 1 à 10) — pour aller plus loin : meilleures dates, escales malignes, frais cachés, négociation… Cliquez « ✨ Lancer dans Claude » et l'IA fait la recherche avec votre abonnement Claude.

🔥 Offres en direct

Les prix réels, en temps réel — sans IA, sans clé, sans attente.

Ouvre Google Flights avec votre recherche : prix réels, calendrier des jours les moins chers, réservation directe.

Recherche Skyscanner intégrée

Si le module Skyscanner ne s'affiche pas ci-dessus (bloqueur de pub, réseau…), utilisez le bouton Google Flights à gauche : mêmes prix réels.
